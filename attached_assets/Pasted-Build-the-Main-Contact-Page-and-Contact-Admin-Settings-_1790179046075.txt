4. Enquiry Delivery
When a valid form is submitted:

Send the enquiry to the main Contact email configured in the Contact settings.
Send a notification to the primary Contact mobile number using the project’s configured SMS or WhatsApp delivery method.
Show an on-page success confirmation after the submission is accepted.
If the visitor provides an email address, send an acknowledgement email when the configured email system supports it.
The enquiry notification should include:

Student/parent name
Mobile number
Email if provided
Selected course
Message if provided
Submission date and time
Source page
Do not show a false success message if delivery fails.

If email, SMS, or WhatsApp delivery requires an integration:

Use the project’s supported integration flow.
Do not expose API keys, passwords, or tokens.
Do not hardcode credentials.
Return a clear configuration error if delivery is unavailable.
Do not silently discard enquiries.
