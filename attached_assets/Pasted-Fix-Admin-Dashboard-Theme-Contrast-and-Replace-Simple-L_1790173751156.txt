2. Add Admin-Specific Theme Tokens
The public theme and admin theme should use the same selected theme colors, but the admin dashboard needs its own semantic mapping.

Create or use admin-specific variables such as:

--admin-primary
--admin-accent
--admin-surface
--admin-surface-soft
--admin-background
--admin-text
--admin-text-muted
--admin-on-primary
--admin-on-accent
--admin-border
--admin-input-background
--admin-focus

Use these variables for admin components instead of applying the raw primary or accent color directly to text.

For example:

Light card:
  background: admin surface
  heading: admin text
  label: admin text
  helper text: admin text muted
  border: admin border
Primary button:
  background: admin primary
  text: admin on primary
Accent badge:
  background: light accent tint
  text: dark readable foreground
  border: accent

Do not use white text on a light accent background.

Do not use dynamic runtime Tailwind class names such as:

text-[${accentColor}]
bg-[${primaryColor}]

Use stable CSS classes and CSS custom properties.
