7. Enquiry Delivery Requirements
When a form is submitted successfully:

Send the enquiry notification to the main email configured under Contact settings.
Send the enquiry notification to the primary mobile number configured under Contact settings using the project’s supported SMS or WhatsApp delivery method.
Show a clear confirmation message to the person who submitted the form.
If the visitor provided an email address, send an acknowledgement to that email where the configured email system supports it.
The enquiry notification should include:

Name
Mobile number
Email if provided
Selected course
Message if provided
Submission date and time
Source page
Do not silently report success if delivery fails.

If email or SMS/WhatsApp delivery requires a provider:

Use the project’s existing integration if one exists.
Otherwise add the required integration/configuration through the project’s supported secure secrets/integration flow.
Never expose API keys, passwords, or tokens in the dashboard or source code.
Show a clear admin-facing error if delivery is not configured.
The on-page success message should only be shown after the submission has been accepted successfully.
